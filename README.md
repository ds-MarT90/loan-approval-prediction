# Loan Approval Prediction

Machine Learning project comparing three classification models for predicting loan approval decisions.

## Project Overview

The project covers the complete machine learning workflow:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Data Preprocessing
- Logistic Regression
- Decision Tree
- Random Forest
- Model Evaluation

The notebook also includes model interpretation, business conclusions and a comparison of different classification algorithms.

## Results

- Logistic Regression achieved solid baseline performance.
- Decision Tree significantly outperformed the linear model.
- Random Forest achieved the highest ROC AUC score while providing only a marginal improvement over Decision Tree.
